# lavaanExtra: Convenience Functions for Package 'lavaan'

Affords an alternative, vector-based syntax to 'lavaan', as well as
other convenience functions such as naming paths and defining indirect
links automatically, in addition to convenience formatting optimized for
a publication and script sharing workflow.
